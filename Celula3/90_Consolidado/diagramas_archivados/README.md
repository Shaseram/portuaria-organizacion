# Diagramas archivados — referencia interna

Esta carpeta conserva los cinco bocetos Mermaid elaborados durante la consolidación técnica de Célula 3.

## Regla de uso

- **No forman parte del Subdocumento 4 entregable.**
- **No se consideran diagramas finales ni aprobados.**
- Pueden consultarse únicamente como apoyo para recordar actores, capas, flujos, zonas y ubicaciones ya acordados.
- El equipo redactor preparará posteriormente los diagramas definitivos con lenguaje, nivel de detalle y diseño propios.
- Si un boceto contradice las fuentes canónicas o el texto acordado por el equipo, prevalecen las fuentes canónicas y el texto corregido.
