# T-11 — Matriz interna de trabajo trazable

**Uso:** consolidar candidatos de A1/A2/A3/C1/C2/C3/C4/D1/D2 antes de copiar las cinco columnas oficiales al formulario final. Esta matriz interna no se entrega como reemplazo del T-11.

## Reglas

1. Cada fila debe corresponder a infraestructura, plataforma, licencia, servicio o hardware ofertado.
2. Cada fila vuelve a una necesidad lógica/transversal, un nodo físico y un cálculo o criterio de cantidad.
3. La justificación incluye función y emplazamiento; no usa lenguaje comercial vacío.
4. Los productos de referencia deben indicar versión/vigencia o criterio de actualización.
5. No incluir precios, costos unitarios, tarifas ni montos.
6. Un componente lógico no genera automáticamente una fila.
7. Si un elemento está incluido dentro de otro servicio, indicarlo para evitar doble conteo.
